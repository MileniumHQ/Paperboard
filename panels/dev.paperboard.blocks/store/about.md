Automate Paperboard by snapping blocks together. Every panel adds its own blocks, so one flow can greet players on your game server, watch your Discord bot and run a command in your terminal.

- **Every panel's blocks** - Start a flow when a player joins, a server crashes or a command finishes.
- **Projects** - Keep each automation in its own project, and switch it off when you don't need it.
- **Runs in the background** - Flows keep running with Blocks closed.
- **See what happened** - The console shows what your flows log, and a failed step says why.
- **More than events** - Logic, math, text, lists, time, variables, functions and web requests are built in.
- **Export and back up** - Save a project to a file, or back up every project at once.
