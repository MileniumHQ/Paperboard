The Blocks panel lets you automate Paperboard by snapping blocks together. Every panel you install adds its own blocks, so one flow can greet players on your game server, watch your Discord bot and run a command in your terminal.

- **Every panel's blocks** - Each panel brings its commands, values and events. Start a flow when a player joins, a server crashes or a command finishes, and pick a server or bot from a dropdown.
- **Projects** - Keep each automation in a project of its own, with a preview of its canvas. Switch a project off to stop its flows from starting, or click Run to start one yourself.
- **Runs in the background** - Flows run in Blocks' service, so they keep reacting to events with Blocks closed.
- **See what happened** - The console shows every line your flows log, as they run. When a step fails, you see why, and a Try block lets a flow handle the failure itself.
- **More than events** - Logic, math, text, lists, time, variables, functions and web requests come built in.
- **Export and back up** - Save a project's flows to a file and import them anywhere, or back up every project and load a backup later.
