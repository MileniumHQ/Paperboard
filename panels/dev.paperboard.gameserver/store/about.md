Host Minecraft and game servers on your computer without the hassle of learning a terminal. The Game Server panel is a full-featured server hosting dashboard that brings all your server management tasks into one convenient interface.

- **All your servers** - Keep several Minecraft and Terraria servers running independently. The Servers home brings you to each server’s console, players, worlds and settings. Each server has its own Actions project, backup schedule and widget selection. Existing servers migrate without moving their files.
- **No setup required** - You don't need to install anything. Paperboard handles software installs and server downloads automatically. Just select the version you want to play on and you're good to go.
- **Automatic plugin management** - Install plugins just by searching their name. Update all of them to the latest version in just a click. Installing plugins has never been easier.
- **Update in seconds** - Update the server to whatever version of Minecraft you want just by selecting it. This panel also supports Paper, Fabric, NeoForge and Forge, and you can switch between them at any time.
- **And more...** - Manage players at a glance, modify server settings and game rules, view a server map, switch between worlds, and more.
- **Modpacks** - Install a whole modpack from Modrinth in one go on your Fabric, NeoForge, or Forge server.
- **Backups** - Back up your server to your computer, Google Drive, or an S3 bucket, on a schedule or whenever you want. Minecraft pauses saving during the copy. Terraria saves and stops before backup or restore, then restarts if it was running, including scheduled backups.

Terraria vanilla uses official verified publisher downloads and supports worlds, options, console, status widgets and independent backups. Linux x64 is the verified server route; client-join certification is required before release. Windows x64 and Intel Mac await certification; Apple Silicon is unavailable. Pick tModLoader at setup to play with mods: search the Steam Workshop and install a mod, with what it requires, in one click. Terraria has no Minecraft-only tools or player/MOTD widgets.
