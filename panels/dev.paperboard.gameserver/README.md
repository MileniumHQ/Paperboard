# Game Server

Host Minecraft and game servers on your computer without the hassle of learning a terminal. The Game Server panel is a full-featured server hosting dashboard that brings all your server management tasks into one convenient interface.

- **Several servers** - The Servers home lists up to 50 independent game servers. Add one in a setup dialog, open its card to manage it, and return with Back to Servers. Each has its own console, players, worlds, software, port claims, Actions project, backups and schedule. Widgets have a Server option. Rename or remove a server from its card; removal stops it and keeps its files and backups.
- **Existing servers** - Your original server is migrated once without moving its directory or changing its installed software. Its backup history and schedule stay with it. Existing project-less Actions keep forwarding to it until v0.5; new flows should choose its project.
- **No setup required** - You don't need to install anything. Paperboard handles software installs and server downloads automatically. Just select the version you want to play on and you're good to go.
- **Automatic plugin management** - Install plugins just by searching their name. Update all of them to the latest version in just a click. Installing plugins has never been easier.
- **Update in seconds** - Update the server to whatever version of Minecraft you want just by selecting it. This panel also supports Paper, Fabric, NeoForge and Forge, and you can switch between them at any time.
- **And more...** - Manage players at a glance, modify server settings and game rules, view a server map, switch between worlds, and more.

## Game modules

Minecraft Java, Terraria (vanilla and tModLoader), Team Fortress 2 and Palworld are bundled; Terraria, Team Fortress 2 and Palworld run on Linux x64 and Windows x64. Each has its console, players, options, per-server ports, vault passwords, versions and the full Backup API. On Windows, a computer without XNA Framework 4.0 (Terraria) or the Visual C++ runtime (Palworld) gets them from Origami at the first start, placed beside the server; nothing is installed into Windows. Complete the owner client-join checklist before release. See [GAMES.md](GAMES.md) for the bundled module contracts, shared infrastructure and future game requirements.
