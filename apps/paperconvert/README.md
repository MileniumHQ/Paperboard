## PaperConvert
This is a file converter that runs entirely in the browser, similar to CloudConvert or other online converter sites, but local.

It's a promo for Paperboard, but it hasn't been tested or finished. It's not in the focus.

If you want to run it anyway, be my guest.

```zsh
cd apps/paperconvert
bun run dev
```

PaperConvert is open-source under MIT.
