Today, Paperboard Beta 2.1 is released. The update should be installed automatically the next time you restart Paperboard, but if you don't see yourself on Beta 2.1 (top left corner), it's worth downloading the update from our site manually.

Here's some of what's been fixed:

- The Calculate block in Actions can now only do plain arithmetic.
- Minecraft 1.17 servers now run on Java 17.
- Electron and the Java 21 and 25 runtimes have been updated with their own security fixes.
- Other bug and security patches are included across the daemon and network features.

Additionally, this month has been crazy for cybersecurity. If any packages Paperboard relies on have high vulnerabilities, the app will be updated accordingly. Due to the current security situation, I'll be taking a modest approach to promoting the app.
