I'm overwhelmingly happy with the reception Paperboard has had over the past couple days. This has been a great release so far! To make it an even better experience, I've pushed an update fixing many bugs for you all. See you at Beta 2!

## New

- **Force CPU** in the AI panel, for when models run out of graphics memory.
- **Custom system prompts** in the AI panel.
- **Copy** AI replies and your own prompts.
- **Reload the Panel Library** by right-clicking it in the sidebar.
- **Quit Paperboard** from Settings.

## Fixed

- Copy and paste in the Terminal, and right-click menus in text fields.
- Terminal tabs and the Actions canvas now stay in sync across windows.
- AI replies no longer vanish if you switch chats while one is being written.
- Ollama setup no longer fails on slow downloads.
- Game Server setup, mod and plugin compatibility, and player heads.

I'd also like to credit [rerrorate777](https://github.com/rerrorate777) on GitHub for reporting pretty much all of these bugs.
