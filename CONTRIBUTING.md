# Contributing (thank you!)

So you want to improve the repo. First of all, thank you so much!

Contributing to Paperboard should be easy! Branch out of main and submit a PR with your change. Use conventional commit styles (feat:, chore:, etc).

Before submitting a PR, it's also worth submitting an issue or emailing me (tails@pxlkt.com) so your effort isn't wasted. That's not for bugs, you can also inquire about feature suggestions and anything else!

Paperboard is an agent-driven project, and therefore I highly recommend you use one to contribute to the project. That is not an excuse to blame an agent for bad code. :)

In general, coontributing to Paperboard should be easy. There's some great engineering rules in the [AGENTS.md](AGENTS.md).

Paperboard is under PolyForm Noncommercial, so you will have to read the [CLA.md](CLA.md) before posting a change.

I'm incredibly excited to recieve any contributions to Paperboard!
